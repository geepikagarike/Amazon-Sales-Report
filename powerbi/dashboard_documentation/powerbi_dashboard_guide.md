# Power BI Dashboard Guide

The prior visual mockup contained hardcoded illustrative KPI values that were not automatically validated against current data. Do not use those values as report results.

Use [powerbi_final_dashboard_spec.md](./powerbi_final_dashboard_spec.md) for the current four-page report design. It defines visuals and filters from the actual star-schema columns and makes the Market Basket page conditional on real association-rule and benchmark outputs.

No Power BI `.pbix` report is included or created by the Python export process. See [powerbi_final_setup_guide.md](../data_model/powerbi_final_setup_guide.md) for manual import, types, relationships, measures, and final validation steps.
